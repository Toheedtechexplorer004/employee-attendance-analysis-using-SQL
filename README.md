## Project Overview

This project is based on employee attendance and workforce analysis using SQL.
The database stores employee details, attendance records, working hours, and department information.

The main objective of this project is to perform data analysis using SQL queries and generate useful business insights such as attendance tracking, average working hours, salary analysis, and department-wise performance.

---

## Tools Used

* PostgreSQL
* SQL
* VS Code
* GitHub

---

## Database Tables

### 1. Employees Table

Stores employee information:

* Employee ID
* Name
* Department
* Salary

### 2. Attendance Table

Stores attendance records:

* Attendance ID
* Employee ID
* Attendance Date
* Attendance Status
* Working Hours

## Analysis Performed

* Present days count
* Average working hours
* Department-wise employee count
* Highest salary employee
* Employees with low attendance
* Department-wise average salary
* Total working hours per employee
* Attendance percentage analysis
* Department performance analysis

---

## Key Insights

* Some employees have lower attendance compared to others.
* Finance department employees have higher average salaries.
* IT department employees show strong working hour consistency.
* Attendance and working hours can help identify workforce trends.

## Conclusion

This project demonstrates how SQL can be used for data analysis and workforce management.
It also helps in understanding database design, relationships, aggregations, joins, and analytical SQL queries.
